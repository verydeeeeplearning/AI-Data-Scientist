## Failed / Blocked Electron GUI Runs

The normal Playwright `_electron.launch()` route failed because this Codex
session blocks Node `child_process.spawn`.

Probe result:

```text
electron: EPERM spawnSync .\electron\node_modules\electron\dist\electron.exe EPERM
esbuild: EPERM spawnSync .\electron\node_modules\@esbuild\win32-x64\esbuild.exe EPERM
backend: EPERM spawnSync .\dist\ds-agent-backend\ds-agent-api.exe EPERM
powershell.exe via Node spawn: EPERM
cmd.exe via Node spawn: EPERM
```

Direct PowerShell execution of binaries worked:

```powershell
.\electron\node_modules\@esbuild\win32-x64\esbuild.exe --version
.\dist\ds-agent-backend\ds-agent-api.exe --help
```

Therefore, a CDP fallback was created where PowerShell directly starts backend
and Electron, and Node only connects over CDP.

Command attempted:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_electron_e2e_direct_cdp.ps1 -SkipCompile
```

This avoided Node spawn for process startup but still failed at Electron /
Chromium native initialization with a Windows application error dialog.

Observed popup:

```text
electron.exe - Application Error
unknown software exception (0x80000003)
```

Relevant stderr signature:

```text
FATAL:platform_channel.cc(83)] Check failed: . : Access is denied. (0x5)
ERROR:network_sandbox.cc(304)] Failed to grant sandbox access to cache directory ... Access is denied. (0x5)
ERROR:network_sandbox.cc(319)] Failed to grant sandbox access to shared dictionary directory ... Access is denied. (0x5)
ERROR:network_sandbox.cc(408)] Failed to grant sandbox access to network context data directory ... Access is denied. (0x5)
ERROR:network_service_instance_impl.cc(283)] Encountered error while migrating network context data or granting sandbox access
```

This occurred even after trying E2E-only mitigations:

- `--no-sandbox`
- `--disable-gpu-sandbox`
- `--single-process`
- `--in-process-gpu`
- `--disable-crash-reporter`
- `--disable-breakpad`
- `--disable-in-process-stack-traces`
- `--disable-features=NetworkServiceSandbox,...`
- temp `userData`
- renderer sandbox disabled in `BrowserWindow` for E2E only

Conclusion: the blocker is below app code and below Playwright. Chromium /
Electron cannot initialize its Windows sandbox/AppContainer/cache ACL path in
this host session. Continuing to launch Electron only repeats the crash dialog.
