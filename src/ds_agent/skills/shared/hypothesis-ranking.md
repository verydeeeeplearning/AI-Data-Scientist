# Hypothesis Ranking

- Start with a short list of plausible explanations, not a fishing expedition.
- Rank each hypothesis by expected impact, ease of validation, and reversibility.
- Prefer fast falsification checks before complex modeling.
- Record why the top hypotheses were promoted or eliminated.
