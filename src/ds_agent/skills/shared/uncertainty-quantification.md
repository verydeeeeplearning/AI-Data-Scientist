# Uncertainty Quantification

- Report intervals, not just point estimates.
- Use bootstrap intervals when analytical assumptions are weak.
- Use conformal prediction or calibrated uncertainty for predictive systems when feasible.
- Show uncertainty widening under distribution shift or sparse segments.
