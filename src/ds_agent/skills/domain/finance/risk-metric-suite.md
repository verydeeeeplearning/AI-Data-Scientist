# Risk Metric Suite

- Report Value at Risk, Expected Shortfall, and Sharpe ratio where applicable.
- Show tail behavior separately from average-case performance.
- Use stress periods explicitly when evaluating production readiness.
- Align summary tables with audit-friendly reporting formats.
